# 課題A: ジャンプアクション デモ（実装サンプル）

これは大学の3Dゲーム制作課題「課題A（ジャンプアクション）」向けに書いた
**動作の仕組みを示す技術デモ**です。Direct3D9 / D3DX9 を直接呼び出しており、
DXライブラリ等のラッパーは使用していません（注意事項４に対応）。

企画書（様式１・様式２、タイトル・ストーリー・キャラクター設定・画面イメージなど）は
このデモの内容そのままではなく、**必ずご自身の企画として作成・提出してください**。
このコード一式はプログラム実装の参考・出発点として使ってください。

## 実装している内容と課題Aの要件対応

- 地面以外の「台」を2種類用意
  - 静止台（灰色の直方体）: キャラクタがぶつかるとめり込まずに止まる。上に乗ってジャンプ着地できる
  - 樽（茶色の直方体, `movable = true`）: キャラクタが押すと一緒に動く。上に乗ってジャンプ着地できる
- 衝突判定は AABB（軸平行境界ボックス）同士の判定を X軸 → Z軸 → Y軸 の順に
  分離して解決する方式（`main.cpp` の `Player::Update`）。
  - X/Z: めり込み量を計算し、めり込み分だけ押し戻す（静止台）。樽は逆に押した分だけ動かす
  - Y: 落下中に上面へめり込んだら着地（`grounded = true`）、上昇中に下面へめり込んだら頭をぶつけて速度を0にする
- ジャンプは Space キー。地面・台の上のどちらからでもジャンプでき、着地判定も両方に対応

## 操作方法

- 矢印キー / WASD : 移動（進んだ方向を向く）
- Space : ジャンプ
- Esc : 終了

## ビルド方法（Windows + Visual Studio が必要です）

このコードは Linux 上ではビルド・実行できません。以下は Windows 上での手順です。

1. DirectX SDK（例: Microsoft DirectX SDK (June 2010)）をインストールし、
   環境変数 `DXSDK_DIR` が設定されていることを確認する
2. `GameA.sln` を Visual Studio で開く
3. 構成を `Debug` / プラットフォームを `Win32` に設定してビルドする
   （Visual Studio のバージョンにより PlatformToolset の再ターゲットを求められた場合は許可してください）
4. ビルド後、`Bin.Debug\GameA.exe` を実行して動作を確認する（注意事項１）

## 未使用のアセットについて

会話でアップロードされた `leaf3.x` / `wood3.x`（木のモデル、`//VB` `//IB` `//UVB` 済み）は
このデモでは使用していません。動かない障害物として木を使う仕様は課題Bの要件に合致するため、
課題Bで使う場合の素材として温存しています。課題Aの「台」はシンプルな直方体メッシュ
（`D3DXCreateBox`）で代用しています。ご自身のキャラクタ・台のモデルに差し替える場合は、
`D3DXLoadMeshFromX` 等でロードし、`Box` の `halfExtents` を実際のモデルサイズに合わせて
調整してください。
