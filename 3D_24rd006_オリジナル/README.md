## 採点者への説明

### (1) ゲームコンセプトや、ゲームの面白さを書く。

**（以下は実装内容の客観的な説明です。「面白さ」の部分はご自身の言葉で書き足してください）**

地面以外に「ぶつかると止まる静止台」と「押して動かせる樽」の2種類の台を配置したジャンプアクションのデモです。プレイヤーは台にぶつかってもめり込まず、上によじ登る（ジャンプして着地する）か、樽を押しのけて進むかを選べます。

### (2) ゲームの機能やプログラムについて、工夫した点を詳しく書く。

- 衝突判定は AABB（軸平行境界ボックス）同士の判定を **X軸 → Z軸 → Y軸** の順に分離して解決する方式を実装（`main.cpp` の `Player::Update`）。
  - X/Z軸: めり込み量を計算し、めり込んだ分だけキャラクタを押し戻すことで、静止台にのめり込まず自然に止まる。
  - X/Z軸（樽）: 静止台とは逆に、めり込んだ分だけ台自体を押した方向へ動かすことで「台を押して動かす」動作を実現。
  - Y軸: 落下中に台の上面へめり込んだら着地判定（`grounded = true`）、上昇中に台の下面へめり込んだら頭をぶつけて上昇速度を0にする、という処理を分けて実装。
- ジャンプ（Space）は地面・台の上のどちらからでも可能で、着地判定も両方に対応。
- キャラクタの進行方向に合わせて自動で向きを変える簡易的な指向処理と、キャラクタの背後から追従するカメラを実装。
- Direct3D9 / D3DX9 を直接呼び出しており、DXライブラリ等のラッパーは未使用（注意事項４に対応）。

# 付録：ビルド方法（提出前の動作確認用、Windows + Visual Studio が必要）

このコードは Linux 上ではビルド・実行できません。以下は Windows 上での手順です。

1. DirectX SDK（例: Microsoft DirectX SDK (June 2010)）をインストールし、環境変数 `DXSDK_DIR` が設定されていることを確認する
2. `GameA.sln` を Visual Studio で開く
3. 構成を `Debug` / プラットフォームを `Win32` に設定してビルドする（PlatformToolset の再ターゲットを求められたら許可）
4. ビルド後、`Bin.Debug\GameA.exe` を実行して動作を確認する（注意事項１）
